# Nexus Defense — инструкции агентам

## Команды

```bash
# сервер прототипов (с запретом кеша — без него браузер держит
# ES-модули в памяти и правки исходников не видны)
python serve.py 8777

# проверка контракта набора: без браузера и без npm,
# three подменяется заглушкой через module loader
node --import ./tools/register-stub.mjs tools/check-kit.mjs

# перегенерировать справочник по деталям после изменения набора
node --import ./tools/register-stub.mjs tools/dump-kit.mjs
```

Сборки, линтера и тест-раннера нет. Проверка изменений делается открытием
страницы через Playwright: `pageerror` и `console.error` должны быть пусты,
все 22 детали строятся без `NaN`.

## Конвенции

- Язык общения с пользователем и в коммитах — русский, термины — как есть (EN)
- Коммиты прямо в `main`, без веток и PR, императивное наклонение,
  заголовок ≤ 72 символа
- Стиль кода существующий: 2 пробела, без точек с запятой в скобках,
  одинарные кавычки, стрелочные функции, короткие тела без комментариев-рычагов
- Комментарии — только там, где фиксируется **инвариант или грабли**.
  Комментарий «что здесь происходит» не пишется
- Three.js приходит с unpkg, `three` ставится через importmap в HTML

## Устройство

Три независимых слоя, смешивать нельзя:

1. **Набор элементов** — `src/terrain/elements/`. Параметризованные детали
   ландшафта. Ничего не знает о карте.
2. **Компоновщик карты** — **не написан**, его предстоит писать. Собирает
   карту из деталей набора, владеет дорогой и балансом.
3. **Прототипы** — `terrain.html`, `towers.html`, `bestiary.html`.
   Это витрины, а не часть набора.

`terrain.html` — намеренно оставлен монолитным. Он был первой попыткой
сделать карту и не является примером архитектуры.

## Правила работы с набором

- Элемент возвращает **дельту** высоты, а не абсолютную: `h += heightAt(...)`
- Юбку добавляет обёртка `defineElement`, элемент задаёт только форму ядра
- Шаблоны неизменяемы; параметры — через `el.instantiate(params)`
- Функции элементов **не используют `this`** — `this` в стрелках не тот,
  всё приходит аргументом `p`. Порядок аргументов `heightAt`
  — `(x, z, base, ox, oz, p)`, ошибка даёт молчаливый `NaN`
- Новую деталь: добавить в свой файл группы, внести в массив группы,
  прогнать `check-kit` и `dump-kit`
